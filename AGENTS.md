# Agent notes

The moneyline and injury model is in `AGENT_STAT.md`. It does not use Sleeper stats. Regenerate that note with `ffdetails stat-model`.

Convert every time to CST before showing it.

Source times may arrive in ET, MT, PT, or UTC. Convert them to US Central time (`America/Chicago`) and label the result CST. That includes kickoffs, inactive deadlines, practice reports, recorded timestamps, and any other clock time.
